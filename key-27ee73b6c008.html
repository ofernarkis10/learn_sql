חלק א׳איזו שאילתה מחזירה את הרשימה?

בכל שאלה מתוארת רשימה. רק אחת מהשאילתות מחזירה אותה. בחרו אותה.

1

הרשימה המבוקשת: לכל חברת משלוחים, השם שלה ומספר ההזמנות שהיא שלחה. איזו שאילתה מחזירה את הרשימה הזאת?

א
SELECT company_name, COUNT(*) AS orders
FROM shippers
GROUP BY company_name;
ב
SELECT s.company_name, COUNT(*) AS orders
FROM shippers AS s
JOIN orders AS o ON o.ship_via = s.shipper_id
GROUP BY s.company_name;
ג
SELECT s.company_name, SUM(o.order_id) AS orders
FROM shippers AS s
JOIN orders AS o ON o.ship_via = s.shipper_id
GROUP BY s.company_name;
ד
SELECT s.company_name, COUNT(*) AS orders
FROM shippers AS s
JOIN orders AS o ON o.ship_via = s.shipper_id;
תשובה ב

צריך לחבר את orders ב־JOIN, לקבץ לפי חברה ולספור ב־COUNT. א׳ לא מחברת את orders וסופרת שורות בטבלת shippers (1 לכל חברה). ג׳ מסכמת את מספרי ההזמנות במקום לספור אותן. בד׳ חסר GROUP BY, ולכן חוזרת שורה אחת בלבד.

2

הרשימה המבוקשת: הלקוחות מבריטניה שגרים בלונדון. איזו שאילתה מחזירה את הרשימה הזאת?

א
SELECT company_name
FROM customers
WHERE country = 'UK' AND city = 'London';
ב
SELECT company_name
FROM customers
WHERE country = 'UK' OR city = 'London';
ג
SELECT company_name
FROM customers
WHERE country = 'London' AND city = 'UK';
ד
SELECT company_name
FROM customers
WHERE country = 'UK';
תשובה א

שני התנאים צריכים להתקיים יחד, ולכן AND. עם OR (ב׳) נכנסים גם לקוחות מבריטניה שלא גרים בלונדון. בג׳ העמודות הפוכות: אין מדינה בשם London, ולכן לא חוזר אף לקוח. ד׳ מחזירה את כל הלקוחות מבריטניה, גם מערים אחרות.

3

הרשימה המבוקשת: הקטגוריות שיש בהן יותר מ־10 מוצרים, עם מספר המוצרים בכל אחת. איזו שאילתה מחזירה את הרשימה הזאת?

א
SELECT c.category_name, COUNT(*) AS products
FROM categories AS c
JOIN products AS p ON p.category_id = c.category_id
WHERE COUNT(*) > 10
GROUP BY c.category_name;
ב
SELECT c.category_name, COUNT(*) AS products
FROM categories AS c
JOIN products AS p ON p.category_id = c.category_id
GROUP BY c.category_name
HAVING COUNT(*) < 10;
ג
SELECT c.category_name, COUNT(*) AS products
FROM categories AS c
JOIN products AS p ON p.category_id = c.category_id
GROUP BY c.category_name;
ד
SELECT c.category_name, COUNT(*) AS products
FROM categories AS c
JOIN products AS p ON p.category_id = c.category_id
GROUP BY c.category_name
HAVING COUNT(*) > 10;
תשובה ד

תנאי על מספר המוצרים בקבוצה כותבים ב־HAVING, אחרי GROUP BY. ב־WHERE (א׳) האתר מחזיר שגיאה. ב׳ מחזירה קטגוריות עם פחות מ־10 מוצרים, וג׳ מחזירה את כל הקטגוריות בלי סינון.

4

הרשימה המבוקשת: שלוש המדינות שיש בהן הכי הרבה לקוחות, מהגדולה לקטנה. איזו שאילתה מחזירה את הרשימה הזאת?

א
SELECT country, COUNT(*) AS customers
FROM customers
GROUP BY country
ORDER BY customers
LIMIT 3;
ב
SELECT country, COUNT(*) AS customers
FROM customers
GROUP BY country
ORDER BY country DESC
LIMIT 3;
ג
SELECT country, COUNT(*) AS customers
FROM customers
GROUP BY country
ORDER BY customers DESC
LIMIT 3;
ד
SELECT country, COUNT(*) AS customers
FROM customers
GROUP BY country
ORDER BY customers DESC;
תשובה ג

ממיינים לפי מספר הלקוחות מהגדול לקטן (DESC) ולוקחים 3 שורות (LIMIT 3). בלי DESC (א׳) המיון מהקטן לגדול. ב׳ ממיינת לפי שם המדינה, ובד׳ חסר LIMIT, ולכן חוזרות כל המדינות.

5

הרשימה המבוקשת: לכל לקוח, מספר ההזמנות שהוא ביצע. איזו שאילתה מחזירה את הרשימה הזאת?

א
SELECT customer_id, COUNT(*) AS orders
FROM orders
GROUP BY customer_id;
ב
SELECT customer_id, COUNT(*) AS orders
FROM orders
GROUP BY order_id;
ג
SELECT customer_id, COUNT(*) AS orders
FROM orders;
ד
SELECT customer_id, COUNT(DISTINCT customer_id) AS orders
FROM orders
GROUP BY customer_id;
תשובה א

בטבלת orders יש שורה לכל הזמנה. מקבצים לפי לקוח וסופרים את השורות. ב׳ מקבצת לפי הזמנה, ולכן בכל שורה יוצא 1. בג׳ חסר GROUP BY, ולכן חוזרת שורה אחת. ד׳ סופרת לקוחות שונים בתוך הקבוצה של כל לקוח, ותמיד יוצא 1.

6

הרשימה המבוקשת: לכל מוצר, השם שלו וסך הכמות שנמכרה ממנו. איזו שאילתה מחזירה את הרשימה הזאת?

א
SELECT p.product_name, SUM(od.quantity) AS total_quantity
FROM products AS p
JOIN order_details AS od ON od.product_id = p.product_id
GROUP BY od.order_id;
ב
SELECT p.product_name, COUNT(od.quantity) AS total_quantity
FROM products AS p
JOIN order_details AS od ON od.product_id = p.product_id
GROUP BY p.product_id;
ג
SELECT p.product_name, AVG(od.quantity) AS total_quantity
FROM products AS p
JOIN order_details AS od ON od.product_id = p.product_id
GROUP BY p.product_id;
ד
SELECT p.product_name, SUM(od.quantity) AS total_quantity
FROM products AS p
JOIN order_details AS od ON od.product_id = p.product_id
GROUP BY p.product_id;
תשובה ד

סך הכמות הוא SUM של quantity, בקבוצה לכל מוצר. א׳ מקבצת לפי הזמנה ולא לפי מוצר. ב׳ סופרת בכמה שורות הזמנה המוצר מופיע, וג׳ מחשבת את הכמות הממוצעת בשורה.

חלק ב׳משאלה מילולית לשאילתה

בכל שאלה, כל ארבע השאילתות מחזירות עמודה עם אותו שם. השם מתאר את מה שהשאלה מבקשת. בחרו את השאילתה שבאמת מחשבת אותו.

א
SELECT COUNT(*) AS active_seafood_products
FROM products AS p
JOIN categories AS c ON c.category_id = p.category_id

SELECT COUNT(*) AS active_seafood_products

ד
SELECT COUNT(*) AS active_seafood_products

שני התנאים צריכים להתקיים יחד, ולכן AND. מוצר שנמכר הוא discontinued = 0. עם OR (א׳) נספרים כל המוצרים שנמכרים מכל הקטגוריות. ג׳ סופרת שורות בטבלת הקטגוריות.

מה סך דמי המשלוח של ההזמנות שנשלחו לגרמניה בשנת 2017?

א
SELECT SUM(freight) AS germany_freight_2017
FROM orders
WHERE ship_country = 'Germany' AND YEAR(order_date) = 2017;
ב
SELECT AVG(freight) AS germany_freight_2017
FROM orders
WHERE ship_country = 'Germany' AND YEAR(order_date) = 2017;
ג
SELECT SUM(freight) AS germany_freight_2017
FROM orders
WHERE ship_country = 'Germany' OR YEAR(order_date) = 2017;
ד
SELECT COUNT(freight) AS germany_freight_2017
FROM orders
WHERE ship_country = 'Germany' AND YEAR(order_date) = 2017;
תשובה א

"סך" הוא SUM, ושני התנאים יחד הם AND. AVG נותן ממוצע, COUNT נותן מספר הזמנות, ו־OR מוסיף את כל ההזמנות של 2017 ואת כל ההזמנות לגרמניה.

התוצאה באתר: 6232.55

אילו לקוחות ביצעו יותר מ־20 הזמנות, וכמה הזמנות ביצע כל אחד?

א
SELECT customer_id, COUNT(*) AS orders_count
FROM orders
WHERE COUNT(*) > 20
GROUP BY customer_id;
ב
SELECT customer_id, COUNT(*) AS orders_count
FROM orders
GROUP BY customer_id
HAVING COUNT(*) > 20;
ג
SELECT customer_id, COUNT(*) AS orders_count
FROM orders
GROUP BY customer_id
ORDER BY orders_count DESC
LIMIT 20;
ד
SELECT customer_id, COUNT(*) AS orders_count
FROM orders
WHERE order_id > 20
GROUP BY customer_id;
תשובה ב

תנאי על תוצאה של COUNT כותבים ב־HAVING, אחרי GROUP BY. ב־WHERE (א׳) האתר מחזיר שגיאה, כי WHERE מסנן שורות לפני הקיבוץ. LIMIT 20 מגביל את מספר השורות בתוצאה, ו־order_id > 20 מסנן מספרי הזמנה.

התוצאה באתר: 3 שורות: ERNSH 30, QUICK 28, SAVEA 31

לכל חברת משלוחים: מה סך דמי המשלוח של ההזמנות שנשלחו לצרפת?

SELECT s.company_name, ROUND(AVG(o.freight), 2) AS france_freight
FROM shippers AS s
JOIN orders AS o ON o.ship_via = s.shipper_id

מסננים את ההזמנות לצרפת ב־WHERE, מקבצים לפי חברת משלוחים ומסכמים ב־SUM. א׳ מחשבת ממוצע, ב׳ מסכמת את ההזמנות לכל המדינות, וד׳ מקבצת לפי מדינה ומחזירה שורה אחת לכל החברות יחד.

מה המחיר הממוצע של מוצר בכל קטגוריה, מעוגל לשתי ספרות, מהגבוה לנמוך?

א
SELECT c.category_name, ROUND(AVG(p.unit_price), 2) AS avg_unit_price

JOIN categories AS c ON c.category_id = p.category_id
GROUP BY c.category_name

ב
SELECT c.category_name, AVG(ROUND(p.unit_price, 2)) AS avg_unit_price

GROUP BY c.category_name
ORDER BY c.category_name DESC;
ד
SELECT c.category_name, ROUND(SUM(p.unit_price) / 8, 2) AS avg_unit_price

השאילתה צריכה להחזיר לכל קטגוריה את מספר המוצרים שלה, אבל היא מחזירה שורה אחת בלבד. מה צריך להוסיף?

SELECT c.category_name, COUNT(*) AS products
FROM products AS p
JOIN categories AS c ON c.category_id = p.category_id;
אאת השורה HAVING COUNT(*) > 0
באת המילה DISTINCT אחרי SELECT
גאת השורה GROUP BY c.category_name
דאת השורה ORDER BY c.category_name
תשובה ג

בלי GROUP BY, הפונקציה COUNT מסכמת את כל השורות לשורה אחת. GROUP BY c.category_name יוצר קבוצה לכל קטגוריה, ו־COUNT סופר בכל קבוצה בנפרד. HAVING, DISTINCT ו־ORDER BY לא יוצרים קבוצות, ולכן התוצאה נשארת שורה אחת.

מה ההבדל בין WHERE לבין HAVING?

אאין הבדל, אפשר להשתמש בכל אחד מהם בכל מקום
בWHERE מסנן שורות לפני הקיבוץ, ו־HAVING מסנן קבוצות אחרי הקיבוץ
גHAVING מסנן שורות לפני הקיבוץ, ו־WHERE מסנן קבוצות אחרי הקיבוץ
דWHERE משמש לסינון טקסט, ו־HAVING משמש לסינון מספרים
תשובה ב

WHERE פועל על כל שורה בנפרד, לפני GROUP BY, ולכן אי אפשר לכתוב בו COUNT או SUM. HAVING פועל אחרי GROUP BY, על כל קבוצה, ולכן בו כותבים תנאים כמו COUNT(*) > 5.

איזה תנאי שקול לתנאי unit_price BETWEEN 10 AND 20?

אunit_price > 10 AND unit_price < 20
בunit_price >= 10 OR unit_price <= 20
גunit_price > 10 AND unit_price <= 20
דunit_price >= 10 AND unit_price <= 20
תשובה ד

BETWEEN כולל את שני הקצוות, ולכן גם מחיר 10 וגם מחיר 20 נכנסים. שני התנאים צריכים להתקיים יחד, ולכן AND. עם OR (ב׳) כל המוצרים מקיימים את התנאי. בשני המקרים חוזרים 29 מוצרים.

איזו מהשאילתות תחזיר הודעת שגיאה באתר?

א
SELECT country, COUNT(*) AS n
FROM customers
GROUP BY country
HAVING COUNT(*) > 5;
ב
SELECT country, COUNT(*) AS n
FROM customers
WHERE COUNT(*) > 5
GROUP BY country;
ג
SELECT country, COUNT(*) AS n
FROM customers
WHERE country <> 'USA'
GROUP BY country;
ד
SELECT country, COUNT(*) AS n
FROM customers
GROUP BY country
ORDER BY n DESC;
תשובה ב

פונקציית צבירה כמו COUNT אסורה ב־WHERE, כי WHERE פועל על כל שורה לפני הקיבוץ. האתר מחזיר misuse of aggregate: COUNT(). תנאי על קבוצה כותבים ב־HAVING.

באיזה סדר מבצע מסד הנתונים את חלקי השאילתה?

אSELECT, FROM, WHERE, GROUP BY, HAVING, ORDER BY
בFROM, WHERE, GROUP BY, HAVING, SELECT, ORDER BY
גFROM, GROUP BY, WHERE, HAVING, SELECT, ORDER BY
דFROM, WHERE, HAVING, GROUP BY, ORDER BY, SELECT
תשובה ב

קודם FROM בוחר את הטבלאות וה־JOIN מחבר אותן. אחר כך WHERE מסנן שורות, GROUP BY מקבץ, HAVING מסנן קבוצות, SELECT מחשב את העמודות, ורק בסוף ORDER BY ממיין. לכן אפשר להשתמש ב־ORDER BY בכינוי שהוגדר ב־SELECT.

מה התפקיד של החלק ON o.ship_via = s.shipper_id בשאילתה?

SELECT o.order_id, s.company_name
FROM orders AS o
JOIN shippers AS s ON o.ship_via = s.shipper_id;
אלסנן רק הזמנות שנשלחו
בלקבץ את ההזמנות לפי חברת המשלוחים
גלמיין את ההזמנות לפי מספר חברת המשלוחים
דלקבוע לכל הזמנה איזו שורה בטבלת shippers מתאימה לה
תשובה ד

ON הוא תנאי החיבור של ה־JOIN. לכל הזמנה הוא מחפש בטבלת shippers את השורה שבה shipper_id שווה ל־ship_via של ההזמנה, וכך כל הזמנה מקבלת את שם החברה ששלחה אותה. הוא לא מסנן, לא מקבץ ולא ממיין.
