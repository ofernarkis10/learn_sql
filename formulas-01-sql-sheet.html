דף נוסחאות SQL

מבנה משפט, סדר ביצוע ופונקציות · הדוגמאות על טבלאות Northwind (שמות כמו ב־sql-practice.com)

התחביר: SQLite, כמו ב־sql-practice.com · הבדלים בניבים אחרים בסעיף 13

1מבנה משפט SELECT

SELECT עמודות FROM טבלה [JOIN טבלה2 ON חיבור] [WHERE תנאי על שורות] [GROUP BY עמודות] [HAVING תנאי על קבוצות] [ORDER BY עמודות [DESC]] [LIMIT n];
רק SELECT ו־FROM חובה. הסדר שבו כותבים את החלקים קבוע.

2סדר הביצוע

1FROM JOIN
2WHERE
3GROUP BY
4HAVING
5SELECT
6ORDER BY
7LIMIT
מסקנה: כינוי שנוצר ב־SELECT (AS total) בטוח להשתמש בו ב־ORDER BY. ב־WHERE אסור. SQLite מרשה אותו גם ב־GROUP BY וב־HAVING, אבל ברוב הניבים האחרים זו שגיאה, ולכן נהוג לחזור שם על הביטוי המלא.

3בחירה, כינוי ומיון

SELECT *
כל העמודות
units_in_stock * unit_price AS stock_value
עמודה מחושבת עם שם חדש
SELECT DISTINCT country
כל ערך פעם אחת בלבד
ORDER BY a DESC, b ASC
מיון לפי a מהגדול לקטן, ובשוויון לפי b. ברירת המחדל היא ASC
... ORDER BY x DESC LIMIT 5
רק 5 השורות הראשונות (אחרי המיון). נכתב בסוף השאילתה

4תנאים ב־WHERE

= <> < > <= >=
שווה, שונה, קטן, גדול, קטן או שווה, גדול או שווה
unit_price BETWEEN 10 AND 20
כולל את שני הקצוות: 10 ≤ x ≤ 20
country IN ('USA', 'UK')
שווה לאחד מהערכים ברשימה
product_name LIKE 'C%'
% = כל רצף תווים (גם ריק), _ = תו אחד בדיוק. LIKE לא מבחין בין אותיות גדולות לקטנות, אבל = כן: = 'chai' לא ימצא את Chai
shipped_date IS NULL / IS NOT NULL
בדיקת ערך חסר. = NULL לא עובד אף פעם
NOT → AND → OR
סדר הקדימות. בספק, שמים סוגריים: (a OR b) AND c

5פונקציות צבירה

COUNT(*)
מספר השורות
COUNT(col)
מספר השורות שבהן col אינו NULL
COUNT(DISTINCT col)
מספר הערכים השונים
SUM(col) AVG(col)
סכום, ממוצע
MIN(col) MAX(col)
ערך קטן ביותר, גדול ביותר (גם לטקסט ולתאריכים)
NULL: כל הפונקציות מלבד COUNT(*) מדלגות על NULL. AVG מחלקת רק במספר הערכים שאינם NULL.

6קיבוץ: GROUP BY ו־HAVING

SELECT country, COUNT(*) AS n FROM customers WHERE city <> 'London' GROUP BY country HAVING COUNT(*) > 5 ORDER BY n DESC;
כלל הזהב: כל עמודה ב־SELECT שאינה בתוך פונקציית צבירה צריכה להופיע ב־GROUP BY. SQLite לא נותן על זה שגיאה, אבל מציג ערך משורה מקרית בקבוצה.
WHEREHAVING
מסנןשורותקבוצות
מתילפני הקיבוץאחרי הקיבוץ
COUNT, SUM ...אסורמותר
GROUP BY YEAR(order_date), ship_via
קיבוץ לפי ביטוי ולפי כמה עמודות: קבוצה לכל צירוף

7חיבור טבלאות: JOIN

FROM orders AS o JOIN customers AS c ON c.customer_id = o.customer_id
[INNER] JOIN
רק שורות שיש להן התאמה בשתי הטבלאות
LEFT JOIN
כל השורות מהטבלה השמאלית (הראשונה). בלי התאמה: NULL בעמודות של השנייה
LEFT JOIN ... WHERE o.order_id IS NULL
מציאת שורות שאין להן התאמה (לקוחות בלי הזמנות)
employees e JOIN employees m ON e.reports_to = m.employee_id
חיבור טבלה לעצמה: חובה שני כינויים
שימו לב: אחרי JOIN מטבלה של "אחד" לטבלה של "רבים", כל שורה מהצד של ה"אחד" חוזרת כמה פעמים. לספירה נכונה: COUNT(DISTINCT ...).

8פונקציות מספר

ROUND(x, 2)
עיגול ל־2 ספרות אחרי הנקודה. ROUND(x, 0) = עיגול למספר שלם
CEIL(x) FLOOR(x)
עיגול למעלה, עיגול למטה
ABS(x)
ערך מוחלט
a % b
שארית החלוקה
CAST(x AS INTEGER) CAST(x AS TEXT)
המרת סוג. CAST(78.24 AS INTEGER) = 78 (חותך, לא מעגל). לעיגול משתמשים ב־ROUND
חילוק שלמים: ב־SQLite 93 / 21 = 4. כדי לקבל 4.43: 93 * 1.0 / 21.

9פונקציות טקסט

UPPER(s) LOWER(s)
אותיות גדולות, אותיות קטנות
LENGTH(s)
אורך הטקסט
SUBSTR(s, 1, 3) SUBSTR(s, -3)
3 התווים הראשונים, 3 התווים האחרונים
SUBSTR(s, 2, 4)
4 תווים החל מהתו השני (המיקום הראשון הוא 1). גם SUBSTRING עובד
first_name || ' ' || last_name
חיבור טקסטים. + בין טקסטים לא מחבר: הוא מחזיר 0 בלי הודעת שגיאה
TRIM(s) REPLACE(s, 'a', 'b')
הסרת רווחים מהקצוות, החלפת טקסט

10פונקציות תאריך

YEAR(d) MONTH(d) DAY(d)
שנה, חודש, יום מתוך תאריך. עובד באתר. ב־SQLite רגיל: strftime('%Y', d), strftime('%m', d)
julianday(end) - julianday(start)
מספר הימים מ־start עד end
date(d, '+7 days')
התאריך d ועוד 7 ימים. גם '-1 month', '+1 year'
date('now')
התאריך של היום
order_date >= '2017-01-01' AND order_date < '2018-01-01'
טווח של שנה שלמה. תאריך נכתב כטקסט בתבנית YYYY-MM-DD

11תנאים בתוך שאילתה

CASE WHEN unit_price < 20 THEN 'Budget' WHEN unit_price < 50 THEN 'Standard' ELSE 'Premium' END AS price_band
התנאים נבדקים מלמעלה למטה, והראשון שמתקיים קובע. בלי ELSE, ערך שלא מתאים לאף תנאי יקבל NULL.
SUM(CASE WHEN discontinued = 1 THEN 1 ELSE 0 END)
ספירה מותנית: כמה שורות מקיימות תנאי
COALESCE(region, '-') IFNULL(region, '-')
אם region הוא NULL, מחזיר '-'

12תת־שאילתות, WITH וחלונות

WHERE unit_price > (SELECT AVG(unit_price) FROM products)
תת־שאילתה שמחזירה ערך אחד
WHERE customer_id IN (SELECT customer_id FROM orders)
תת־שאילתה שמחזירה רשימה
WHERE NOT EXISTS (SELECT 1 FROM orders o
WHERE o.customer_id = c.customer_id)
אין אף שורה מתאימה
FROM (SELECT ...) AS t
תת־שאילתה כטבלה. חובה לתת לה כינוי
WITH t AS (SELECT ...)
SELECT ... FROM t;
CTE: שלב עם שם, שהשאילתה הראשית קוראת כמו טבלה
RANK() OVER (PARTITION BY category_id
ORDER BY unit_price DESC)
דירוג בתוך כל קבוצה, בלי לאחד שורות. גם ROW_NUMBER(), DENSE_RANK()
SUM(x) OVER (ORDER BY m) LAG(x) OVER (ORDER BY m)
סכום מצטבר, הערך של השורה הקודמת

14טעויות נפוצות

WHERE COUNT(*) > 5 -- שגיאה
תנאי על צבירה הולך ל־HAVING
WHERE region = NULL -- תמיד ריק
כותבים IS NULL
SELECT country, city, COUNT(*) ... GROUP BY country -- תוצאה מטעה
city צריכה להופיע גם ב־GROUP BY. בלי זה SQLite מציג עיר אחת מקרית לכל מדינה
SUM(p.unit_price) * SUM(od.quantity) -- לא נכון
צריך SUM(p.unit_price * od.quantity): קודם כופלים בכל שורה, אחר כך מחברים
first_name + ' ' + last_name -- מחזיר 0
ב־SQLite מחברים טקסטים עם ||
SELECT TOP 5 ... -- שגיאה
ב־SQLite כותבים LIMIT 5 בסוף השאילתה
WHERE a OR b AND c
AND מתבצע לפני OR. אם התכוונתם אחרת: (a OR b) AND c
'USA' ולא "USA"
טקסט ותאריכים כותבים בגרש אחד
